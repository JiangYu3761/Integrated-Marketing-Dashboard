# 飞书同步总表

Mac App 的「飞书同步总表」可在窗口内跨项目查看本机任务、已提交日报和关联记录。支持按项目、产品、人员、日期、工作状态和同步状态筛选。选择日报或任务可回到对应编辑页。

## 连接飞书多维表格

1. 在飞书开放平台准备企业自建应用，开通多维表格读取字段、检索记录、创建和更新记录所需权限，发布应用版本，授予应用目标表格的写入权限。
2. 在目标多维表中准备以下同名文本列，第一列可使用“事项”作为主字段。日期按北京时间的业务日期写成文本，以保持和本机口径一致。

   本地ID、类型、事项、项目、产品、负责人、行动日、截止日、状态、重点、重点原因、板块、来源日报、内容

3. 在 App 的「飞书同步总表 → 连接设置与字段映射」填写 App ID、App Secret、Base Token（多维表格 app_token）和 Table ID（tbl 开头的表 ID）。点击「验证连接并开始同步」。系统验证飞书应用和目标表字段后保存配置，自动发送本机已提交的日报及其中确认的任务。首次配置建议使用独立测试表核对实际数据。
4. 修改已提交事项后，App 对同一条远端记录进行更新。草稿保存在本机，普通本地任务显示“仅本机”。同步失败时可在具体行重试，或点击「同步待处理项」。

凭据和授权令牌不会写入浏览器存储或前端代码。Mac 本地服务在当前用户的 `~/Library/Application Support/com.jiangyu3761.integrated-marketing-dashboard/Feishu/` 保存权限为 0600 的连接文件，读取配置接口仅返回非密钥字段。获得这个目录的用户可以读取连接文件，请按本机用户权限保护它。连接配置和远端映射独立于网页的业务数据备份。

## 同步口径

- 业务记录保持稳定 ID，任务使用 `task:<id>`，日报使用 `report:<id>`。日报保留原文，关联任务独立更新，表格中的“来源日报”保存对应的本地日报 ID。
- 连接器按目标 Base、目标表和本地 ID 保存远端记录 ID、内容指纹、成功时间和最近错误。多次保存相同内容会复用既有结果。请求超时后先按本地 ID 查询已创建记录，再处理重试。检测到相同 ID 的多条远端记录会暂停该项。
- 业务操作在本机保存后进入待同步状态。只有飞书接口确认更新，才会显示“已同步”。表内手工修改、云端删除和多设备并发编辑不属于第一版双向同步范围；打开原记录是用户主动选择的外部操作。
- 查看静态网页时仍可浏览本机总表。发送到飞书和连接设置由独立 Mac App 的本机服务提供。
