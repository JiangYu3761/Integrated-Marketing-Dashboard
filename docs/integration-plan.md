# 外部同步计划

当前只有浏览器本地保存，以下连接器尚未实现。

## 数据关系

```text
项目 → 产品 → 任务 → 每日子任务
项目 ↔ 人员
岗位 → 多名人员
```

项目、产品、人员、任务、每日子任务分别使用稳定 ID。任务关联产品和负责人；子任务关联父任务，可以指定不同执行人。

## 后续连接

```text
OpenProject ↔ 连接器 ↔ 飞书多维表格
外部业务 API → 连接器 → 飞书业务记录 → 地图展示
```

- 任务排期、依赖和验收按已约定的 OpenProject 权威字段管理；在飞书修改这些字段时，经过校验后同步。
- 销售、成本、库存和履约等业务记录由来源系统提供，保留来源 ID、统计周期、单位、更新时间。
- 连接器保存两边的记录映射和版本，执行幂等更新、失败重试、冲突处理，防止重复记录和更新循环。
- 人员、项目、产品、阶段计划、任务和每日子任务分别建表，不靠页面行号同步。
- 勾选完成同步状态和实际完成时间。月份、周、日只是同一数据的显示层级，缩放不改变业务日期或状态。
- 凭据存放在连接器服务端；库存流水和账务仍由业务系统处理。

阶段验收与任务完成分别处理。同步接口、权限、运行部署和真实数据验证不属于当前静态模板。
